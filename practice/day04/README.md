# AI 學習的第一課｜第四天：從拋體公式到互動程式

這次練習把同一個物理問題，用不同形式做出來：先算出數字，再透過迴圈觀察軌跡，接著做成可以輸入參數的命令列與視窗介面，最後延伸到本專案的網頁拋射遊戲。

## 我們在練習什麼？

1. **Python 基礎**：變數、算術、格式化輸出、函式、回傳值，以及 `import` 模組。
2. **數學與物理轉成程式**：角度轉弧度、三角函數、水平與垂直分量、最高點、射程和飛行時間。
3. **迴圈與時間**：用 `for` 算出不同時間的位置，觀察炮彈為什麼沿拋物線飛行。
4. **命令列互動**：選單、輸入預設值、數字檢查、例外處理及重複操作。
5. **Tkinter GUI**：視窗、輸入框、按鈕、清單、滑桿、進度條、Canvas、事件與對話框。
6. **把結果畫出來**：將物理座標換成螢幕座標，畫出軌跡、刻度、最高點與射程。
7. **AI 協作開發**：把需求說清楚、檢查生成結果、回報操作問題，再逐步修正與測試。

## 如何執行

使用 Python 3，並確認環境支援 Tkinter。這些練習只使用標準函式庫，不需要安裝第三方套件。先切換到本資料夾，再執行想看的程式：

```sh
python main.py
python "斜向拋射.py"
python "斜向拋射作業版.py"
python test.py
python "GUI教學.py"
python "拋物線軌跡與測算.py"
```

若系統的命令是 `python3`，可將上述 `python` 替換為 `python3`。Tkinter 程式需要桌面圖形環境。

## 拋體運動公式

假設沒有空氣阻力，且起點與落點等高；θ 為弧度，初速度為 v₀，重力加速度為 g：

```text
x(t) = v₀ cos(θ) × t
y(t) = v₀ sin(θ) × t − ½gt²
最高點 H = v₀² sin²(θ) / (2g)
水平射程 R = v₀² sin(2θ) / g
飛行時間 T = 2v₀ sin(θ) / g
```

例如 v₀ = 30 m/s、θ = 45°、g = 9.81 m/s²，應得到 H 約 22.94 m、R 約 91.74 m、T 約 4.32 s。可以修改速度、角度與重力，觀察數字和圖形如何變化。軌跡圖的 X、Y 軸各自縮放，圖形呈現的角度不代表等比例空間角度。

## 從課堂練習到遊戲

[星丘炮戰](../../README.md) 使用相同的速度分解與重力概念，另外加入固定時間步進、風力、像素遮罩地形、角色碰撞、回合狀態、蓄力和多炮彈排程。遊戲用的是畫面像素與遊戲調整值，不是直接套用這裡的公尺單位。

這次實作也練習了把使用者回報轉成修正：坡地卡住要調整碰撞與爬坡；兩隊操作方向要符合直覺；三顆炮彈必須全部結算後才能換回合。

## 整理紀錄與可繼續練習的地方

- 上傳副本將原本沒有副檔名的 `斜向拋射作業版` 命名為 `斜向拋射作業版.py`。
- 上傳副本修正 `main.py` 的 `import testa` 為 `import test`，讓後續函式呼叫能正常執行。
- 原始桌面資料夾未修改。原始炸彈保留方格背景，遊戲使用另一份已去背的素材。
- `GUI.py` 建立了 Label，但沒有呼叫 `pack()` 或 `grid()`，所以文字不會顯示；可以把這當成版面配置練習。
- `for迴圈.py` 會繼續算到落地之後，得到負的 Y；可以練習加入落地停止條件。
- CLI 的角度目前只有建議範圍；可以練習像 GUI 一樣限制輸入，並加入公式測試。
